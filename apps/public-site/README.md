# Public Site

Astro site for public content and design at `https://www.imaginecodebuild.dev`.

## Commands

```bash
npm ci
npm run dev
npm run build
npm run preview
```

Set `PUBLIC_APP_URL` to the private Angular app URL used by login and app links. Production uses:

```text
PUBLIC_APP_URL=https://app.imaginecodebuild.dev
```

Public content and design changes belong in this directory.
