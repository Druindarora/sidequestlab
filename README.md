# SideQuestLab

Monorepo for the public Astro website, private Angular MemoQuiz app, and Spring Boot API.

## Stack

- Public website: Astro (`apps/public-site`)
- Private app: Angular 21 + Angular Material (`frontend`)
- API: Spring Boot / Java 21 (`backend`)
- Database: PostgreSQL + Flyway
- Local services: Docker Compose (`docker-compose.dev.yml`)

## Repository Map

```text
.
├── apps/public-site/       # Astro public site for www.imaginecodebuild.dev
├── frontend/               # Angular private MemoQuiz app
├── backend/                # Spring Boot API
├── doc/                    # Living project, state, quality, and runbook docs
├── ops/db-backup/          # Database backup container and script
├── scripts/                # Local validation, run, quality, and report helpers
├── docker-compose.dev.yml  # Local Postgres and optional app services
└── .env.example            # Environment variable template
```

Start with `doc/project-overview.md` for architecture, `doc/current-state.md` for the implemented snapshot, and `doc/next-slices.md` for immediate pending work. Operational runbooks live under `doc/runbooks/`; backup tooling lives under `ops/db-backup/`.

## Quickstart

1. Create local environment values:

   ```bash
   cp .env.example .env.local
   ```

2. Start local services:

   ```bash
   docker compose -f docker-compose.dev.yml up -d
   ```

3. Start the API:

   ```bash
   ./scripts/run-backend.sh
   ```

4. Start the private app:

   ```bash
   cd frontend && npm ci && npm start
   ```

5. Start the public site:

   ```bash
   cd apps/public-site && npm ci && npm run dev
   ```

Local URLs:

- Public site: `http://localhost:4321`
- Private app: `http://localhost:4200`
- API: `http://localhost:8080`
- Swagger UI: `http://localhost:8080/swagger-ui`

## Validation

Repository validation entry point:

```bash
./scripts/check.sh
```

It runs guardrails, backend tests/package, frontend install/lint/build/tests, and the Astro public-site build.

## OpenAPI Client

When the backend is running on `http://localhost:8080`:

```bash
cd frontend && npm run generate:api
```

Do not edit generated files in `frontend/src/app/api/**` by hand.

## CI

Current GitHub workflows:

- `ci.yml`: push, pull request, and manual CI for backend Maven tests/package plus frontend install/lint/build/tests.
- `weekly-dependency-report.yml`: scheduled/manual frontend npm audit/outdated reports and backend Maven dependency update reports.
- `weekly-coverage.yml`: scheduled/manual coverage baseline generated by `scripts/coverage-report.sh`.

Dependabot is configured for weekly npm updates in `frontend` and Maven updates in `backend`.
